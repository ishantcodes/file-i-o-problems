# file-i-o-problems
After learning File I/O in Python recently, today I practiced it by building 10 small projects based on reading, writing, updating, copying, and analyzing files.

Honestly, these projects felt much more logical than the earlier ones because now I’m starting to understand where things are actually used in real programs. Especially the Hi-score project took a lot of thinking and debugging before it finally worked properly.

Projects I built:
• Finding words inside a file
• Hi-score tracking system using files
• Generating multiplication tables into separate files
• Word censoring inside text files
• Censoring multiple words from files
• Mining log files for specific words
• Finding line numbers from log files
• Creating copies of text files
• Comparing two files
• Wiping file contents using Python

While building these, I practiced:
*File I/O
*reading & writing files
*updating file content
*loops with files
*conditions inside file handling
*string replacement
*logic building
*debugging

One thing I’ve been doing lately is using AI mainly for debugging support or quick references, while focusing on building and solving the logic myself. At this point, I’m getting much better at understanding not just how code works, but also where and why different concepts are actually applied in real projects.

Still learning step by step and trying to stay consistent by building projects daily.
